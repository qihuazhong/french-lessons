# Leçons de français — guided lessons from real videos

Four self-contained French lessons built from real YouTube videos (Easy French,
Français avec Nelly, Bigflo & Oli). Each lesson offers **A2 · B1 · B2 (+ C1)**
parcours, authentic audio clips cut from the video, a floating video panel that
jumps to each excerpt, and **auto-corrected interactive exercises**.

**Live site:** https://qihuazhong.github.io/french-lessons/

## The lessons

| Page | Source | Levels |
|---|---|---|
| `lecon-opinions-impopulaires.html` | Easy French 259 — opinions impopulaires | A2 · B1 · B2 |
| `lecon-ai.html` | Easy French 199 — l'IA au quotidien | A2 · B1 · B2 |
| `lecon-dommage.html` | Bigflo & Oli — « Dommage » (chanson) | A2 · B1 · B2 |
| `lecon-france.html` | Français avec Nelly — la colère des lycéens (actualité) | A2 · B1 · B2 · C1 |

`index.html` is generated from `lessons.json`; every page's side panel and
footer link to the others (regenerated by `tools/add_lessons_nav.py`).

## Adding a new lesson (short version)

Full recipe with commands: **docs/PIPELINE.md**.

1. Fetch captions → `content/<slug>/transcript*.{json,txt}`; download the video
   to `video_src-<slug>/lesson_video.mp4`; run a whisper word-timings pass.
2. Author `content/<slug>/src/part1..5.html` (copy an existing lesson’s parts;
   conventions in docs/CONVENTIONS.md).
3. `python3 tools/build_page.py content/<slug>/src lecon-<slug>.html`
4. Write the per-lesson conjugation script (copy the previous one) and run it.
5. Map spans: `python3 tools/map_spans.py lecon-<slug>.html /tmp/whisper_full_<slug>.json /tmp/map_<slug>.json` → curate `content/<slug>/clip_overrides.json`.
6. Cut + wire: `python3 tools/cut_clips.py lecon-<slug>.html audio-<slug> content/<slug>/transcript*.json video_src-<slug>/lesson_video.mp4 content/<slug>/clip_overrides.json content/<slug>/spans.json 64k` then `python3 tools/add_youtube.py lecon-<slug>.html content/<slug>/clip_overrides.json`
7. Add the lesson to `lessons.json`, run `python3 tools/add_lessons_nav.py` (also regenerates `index.html` and the review deck `progres.html`).
8. Validate (HTML parse, `node --check`, `tools/test_exos.js`) and spot-play clips.

## Grammar roadmap

**parcours.html** lists the grammar to master at each CEFR level, A1 → C2
(92 points from `content/curriculum.json`, grouped by category, with
prerequisites). Each point links to every lesson that teaches it, deep-linked to
the right parcours and heading (`lecon-ai.html?niveau=b1#gram-b1-G2`); points no
lesson covers yet show « Bientôt ». Every point expands into an « Explication
détaillée » (`content/explications/<LEVEL>.json`): what it's for, rules, forms,
3–5 examples with English glosses, common mistakes, a tip. Regenerated by `tools/add_lessons_nav.py`
(or `python3 tools/build_roadmap.py`).

Whenever this browser has progress (signed in or not), `parcours.js` overlays
**your mastery** on every point: Non commencé · Découvert · En cours · Acquis ·
Maîtrisé (or « À revoir » after 90 days without practice), with the evidence
(exercises, success rate, grammar card interval, last activity), a progress
bar per level and « À travailler ensuite »: points already in progress or due
for review first, then points from your current level up (current level =
highest level with at least 2 points « En cours » or beyond; none → from A1),
then untouched gaps below it. Untouched prerequisites below your level are assumed known; a
prerequisite you started but haven't acquired still blocks what depends on it. « Masquer ma progression » shows the generic roadmap.
Rules (`SRS.mastery` in `srs.js`):

| State | Rule |
|---|---|
| Maîtrisé | ≥ 2 exercise sittings ≥ 85 % **and** a grammar card with interval ≥ 21 d — or ≥ 3 sittings ≥ 90 % spread over ≥ 7 days |
| Acquis | ≥ 2 sittings ≥ 80 %, or a grammar card with interval ≥ 7 d |
| En cours | any sitting (even partial) or a reviewed card |
| Découvert | grammar card added, never reviewed |

Accuracy = **first-try** score of each sitting (an answer seen in a correction
never counts as right; redoing an exercise right after is a retry, not a new
sitting), last 5 complete sittings weighted 1 / .8 / .6 / .4 / .2 (newest
first), « presque » = half a point. Points with no lesson yet carry no label.

## Progress & reviews

`srs.js` (loaded by every lesson page) records exercise results. Cards enter the
review deck **explicitly** — opening a lesson registers nothing: click the
speaker of a vocab row / expression card, or the « + Ajouter ces N mots à mes
révisions » button injected above each visible level — it opens a checkbox per
item so you can include/exclude before confirming (« Annuler » or Échap).
**progres.html** is an Anki-style review page: a big centered card (click or
space to flip), solid graded buttons in Anki colours each showing the simulated
next interval (Encore 10 min · Difficile 15 min · Bien 1 j · Facile 4 j on new
cards; keys 1-4, and R replays the audio once flipped), a due forecast chart (Auj. / Demain / 2-3 j / 4-7 j / +7 j),
a 14-day review-history bar chart, due counts, streak, activity log, JSON
export/import, and a reset button. Grammar points can be added to the deck from
each lesson (« + Ajouter ces N point(s) de grammaire »): the card shows the rule
title, the back its explanation and examples. Once
the answer is shown, « Retirer du paquet » removes a card from the deck (confirm
first; re-addable from the lesson — the removal syncs across devices).

**Private lessons** (« Mes leçons privées » on progres.html) record your own
tutoring sessions: a name, a link (video call, shared doc, recording), a date
and notes. Add the words seen in class one per line (`français = traduction`,
optionally `= exemple`; tab or `;` also work): they become review cards under
the lesson key `prive:<id>`, get their own filter chip, and travel with export
/import and Google sync (`doc.priv`, newest edit wins, deletions are
tombstones). Links are restricted to http(s).

Everything is **localStorage-first** (free, offline, no account). Optional $0
cloud sync ties progress to a **Google account**: sign in with Google on
progres.html, and the same progress follows you on every device. It needs a
Worker + D1 (both free) and a public Google Client ID — ~15 minutes once; see
`cloudflare/README.md`, then fill `config.js` (workerUrl + googleClientId).

## Deploying

GitHub Pages serves the `main` branch root.

```bash
git add -A && git commit -m "..." && git push
```

If SSH isn't configured, push over HTTPS with gh as the credential helper:

```bash
git -c credential.helper='!gh auth git-credential' push
```

Pages rebuilds in ~1–2 minutes; verify with `curl -s -o /dev/null -w '%{http_code}' https://qihuazhong.github.io/french-lessons/<file>`.

## Environment prerequisites

- `yt-dlp` (pip), `ffmpeg` (brew), `faster-whisper` (pip; scripts decode audio
  via numpy to avoid PyAV version issues)
- Python 3.12, Node ≥ 20 (only for the exos smoke test / syntax checks)
- `tools/test_exos.js` needs `jsdom` once: `cd tools && npm i jsdom`
